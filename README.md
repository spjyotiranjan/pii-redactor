# PII Redaction

This project redacts personally identifiable information (PII) from DOCX files and embedded images.

It is designed for simple, practical use:
- finds sensitive text like names, email addresses, phone numbers, company names, addresses, dates of birth, and Indian IDs
- replaces them with safe fake values
- removes comments and metadata that may contain hidden sensitive data
- optionally redacts information inside images inside the document
- creates a JSON report with what was redacted and any warnings

---

## Simple flow: how it works

Think of the pipeline like this:

1. Read the DOCX file
   - The code opens the Word file as a ZIP package
   - It looks through XML parts inside the document

2. Detect sensitive values
   - It checks text for patterns such as:
     - email addresses
     - phone numbers
     - websites
     - company names
     - addresses
     - DOBs
     - PAN / Aadhaar / GSTIN / CIN / DIN
     - SSNs and credit cards
   - It can also use Presidio NER if available

3. Replace with safe placeholders
   - Instead of deleting the content, it swaps the real value with a fake but realistic value
   - Example:
     - "Rashi Patil" becomes "John Doe"
     - "rashi.patil@gmail.com" becomes "john.doe@example.com"
     - "KSH International Limited" becomes "Example Company Limited"

4. Clean document metadata and comments
   - It removes:
     - comments
     - tracked deletions
     - revision IDs
     - some metadata fields that may carry author or company information

5. Redact embedded images
   - If the DOCX contains images, the project can process them too
   - It uses OCR to read text from the image
   - If it finds sensitive content, it covers or replaces it
   - It can also detect company logos, ID cards, and QR codes and replace them with safe placeholders

6. Validate the final document
   - It checks that the resulting DOCX is still valid and not corrupted

7. Produce reports
   - It writes a run report showing what was changed
   - It can also generate an evaluation report for metrics and checks

## Project structure

- `run.py` – runs the project
- `pii_redactor/` – main code package
  - `application/` – CLI commands
  - `core/` – shared config and data models
  - `detection/` – detection logic
  - `document/` – DOCX rewriting pipeline
  - `imaging/` – OCR and image redaction
  - `replacement/` – fake replacement values
  - `reporting/` – evaluation and JSON reports
- `tests/` – unit tests
- `output/` – example reports generated by the project

## Installation

Install all required dependencies from the project requirements file:

```bash
python -m pip install -r requirements.txt
```

Then install the project itself in editable mode so the commands are available:

```bash
python -m pip install -e .
```

This includes all required OCR, NLP, and GUI support packages.

---

## GUI usage

You can launch the desktop GUI directly:

```bash
python -m pii_redactor.application.gui
```

Or, after installation, use:

```bash
pii-redact-gui
```

The GUI allows you to:
- choose an input DOCX file
- pick an output folder
- process the document and save the redacted output

---

## CLI usage

The project exposes a command-line tool called `pii-redact` after installation.

You can also run it directly with Python:

```bash
python -m pii_redactor --help
```

### 1) Redact a DOCX file

```bash
python -m pii_redactor redact input.docx output.docx
```

Example:

```bash
python -m pii_redactor redact sample.docx cleaned.docx
```

### 2) Save a run report

```bash
python -m pii_redactor redact input.docx output.docx --run-report output/run_report.json
```

This writes a JSON file with information such as:
- how many replacements were made
- which entity types were found
- whether comments were removed
- whether metadata was scrubbed
- any warnings

### 3) Save an evaluation report

```bash
python -m pii_redactor redact input.docx output.docx --evaluation-report output/evaluation_report.json
```

This adds a quality/evaluation summary to the output.

### 4) Disable image redaction

```bash
python -m pii_redactor redact input.docx output.docx --no-images
```

### 5) Disable Presidio

```bash
python -m pii_redactor redact input.docx output.docx --no-presidio
```

This disables the Presidio-based NLP detection while keeping the rest of the full package installation in place.

### 6) Use a custom seed

```bash
python -m pii_redactor redact input.docx output.docx --seed my-custom-seed
```

The seed controls deterministic replacement values so the same sensitive input gets the same fake replacement each time.

---

## Evaluation mode

The tool can also evaluate detection quality using gold annotations.

### With a gold file

```bash
python -m pii_redactor evaluate --gold gold.json --output output/evaluation.json
```

### Without a gold file

It can generate a synthetic evaluation report automatically:

```bash
python -m pii_redactor evaluate --output output/evaluation.json
```

---

## Example workflow

A very common usage is:

```bash
python -m pii_redactor redact sample.docx redacted_output.docx \
  --run-report output/run_report.json \
  --evaluation-report output/evaluation_report.json
```

This will:
1. read the original DOCX
2. redact sensitive content
3. clean metadata and comments
4. process embedded images if available
5. write the cleaned output
6. generate reports

## What it protects

The project is focused on typical PII and corporate identifiers, including:
- names and people
- company names
- emails
- websites
- phone numbers
- addresses
- dates of birth
- PAN, GSTIN, Aadhaar, CIN, DIN
- SSNs
- credit cards
- IP addresses
